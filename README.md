# 🚀 FreelanceFlow - MERN Freelancing Application

**FreelanceFlow** is a professional full-stack web application designed to connect freelancers with clients. It provides a seamless platform for clients to post jobs and for freelancers to showcase their skills and secure projects.

---

## 🌟 Features

### 👨‍💻 For Freelancers
* **Profile Management:** Create and customize a professional profile showcasing your skills, experience, and portfolio.
* **Job Discovery:** Advanced filtering and search options to find jobs based on categories, budget, and skills.
* **Proposal System:** Submit detailed, professional bids for projects and track their status.
* **Dashboard:** A centralized hub to track active applications, project progress, and earnings.

### 🏢 For Clients
* **Job Posting:** Quickly create job listings with specific requirements, deadlines, and budget ranges.
* **Applicant Management:** Efficiently review freelancer profiles, compare proposals, and manage communications.
* **Hire Talent:** Select the best candidate for your project and initiate collaborations with ease.

### 🛡️ General Features
* **Secure Authentication:** User accounts are protected using **JWT (JSON Web Tokens)** and **bcryptjs** password hashing.
* **Real-time Notifications:** Stay informed with instant updates on job posts, proposals, and messages.
* **Responsive Design:** A fully optimized UI that provides a great experience across mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

### 💻 Frontend
* **React.js:** For building a dynamic and interactive user interface.
* **Redux:** Robust state management for complex application data.
* **Tailwind CSS / Material UI:** Modern styling frameworks for a polished look.

### ⚙️ Backend
* **Node.js & Express.js:** Scalable server-side logic and RESTful API development.
* **JWT & bcryptjs:** Secure user authentication and data protection.

### 🗄️ Database & Storage
* **MongoDB:** NoSQL database for flexible and efficient data storage.
* **Mongoose:** ODM for modeling application data with MongoDB.
* **Cloudinary:** Cloud-based storage for profile pictures and project attachments.

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/Navya2005-coder/MERNPROJECT-FREELANCING-APLLICATION.git`
2. Install dependencies: `npm install` (in both client and server folders)
3. Start the server: `npm start`
